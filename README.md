Clinical Trial Data Analysis Using R and Shiny

Project Overview

This project demonstrates clinical trial data preparation, descriptive statistical analysis, and interactive visualization using R and Shiny.

Dataset

Simulated clinical trial data consisting of 8 subjects assigned to a new treatment or placebo group.

Clinical Trial Concepts

* SDTM-style Demographics (DM)
* SDTM-style Adverse Events (AE)
* Exposure (EX)
* ADaM-style Subject-Level Analysis Dataset (ADSL)
* Safety Population Flag (SAFFL)
* Treatment Start Date (TRTSDT)
* Blood pressure change from baseline

R Shiny Dashboard

The application is designed to allow users to select a treatment group and explore blood pressure results using tables and graphs.

Technologies

* R Programming
* R Shiny
* Descriptive Statistics
* CDISC SDTM and ADaM concepts

Project Files

* ADSL.R — Clinical trial data preparation and analysis
* app.R — Interactive Shiny dashboard

Run the Application

1. Install R and the Shiny package.
2. Open app.R in RStudio.
3. Click Run App.
